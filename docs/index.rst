vsql
====

vsql is a small SQL database that follows the SQL standard. It keeps a whole
database in a single file (or in memory), and you can use it from a terminal
(see :doc:`cli`), from any PostgreSQL client (see :doc:`server`), or embedded
in your own program (see :doc:`language-c` and :doc:`language-v`). It's
written in pure V with no dependencies.

New to vsql? Start with :doc:`quick-start`.
