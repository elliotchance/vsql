INSERT
======

.. contents::

Syntax
------

.. code-block:: text

  INSERT INTO <table_name> [ ( <column_name> , ... ) ]
  [ OVERRIDING { SYSTEM | USER } VALUE ]
  { VALUES ( <value> , ... ) , ... | <query> }
  [ RETURNING { * | <expression> [ AS <name> ] } , ... ]

Without a list of columns, it's every column in the order of the table.

The rows are either the rows of ``VALUES``, or the result of a query (see
:doc:`select`). A query can use ``UNION``, ``EXCEPT``, ``INTERSECT``,
``ORDER BY``, ``OFFSET`` and ``FETCH FIRST``, and it can be in parentheses. Its
result is known before any row is inserted, so a query that reads from the same
table doesn't see the new rows. A ``VALUES`` on its own is always the first form, ``(VALUES ...)`` or
``VALUES ... UNION ...`` is a query, which can't contain ``DEFAULT`` or a
``NULL`` on its own.

Each row must have the same number of values as there are columns, which is an
error ``42601`` otherwise. Columns that aren't listed get their default (see
:doc:`create-table`), which is ``NULL`` if the column doesn't have one. ``NULL``
is an error ``23502`` for a ``NOT NULL`` column, and a row that violates a
``CHECK`` constraint is an error ``23514``. If any row fails, none of the rows
are inserted.

A value in ``VALUES`` can be ``DEFAULT``, which is the default value of the
column.

The value of a generated column must be ``DEFAULT`` in ``VALUES`` (an error
``428C9`` otherwise). A query can have any value of a suitable type for a
generated column, but it's ignored, so ``INSERT INTO t SELECT * FROM t`` works.

An identity column (see :doc:`create-table`) gets the next value of its
sequence when it isn't listed, or its value is ``DEFAULT``. Any other value for
a ``GENERATED ALWAYS`` identity column is an error ``428C9``, unless the
``INSERT`` has ``OVERRIDING SYSTEM VALUE``. A query for that column always needs
one of the ``OVERRIDING`` clauses, even if it has no rows.
``OVERRIDING USER VALUE`` ignores
the values for the identity column, so it always gets the next value. Values
that are inserted don't change the sequence. ``OVERRIDING SYSTEM VALUE`` can't
be used for a ``GENERATED BY DEFAULT`` identity column, and neither can be used
without the identity column (both are an error ``42601``).

The values are converted to the types of the columns. For example, a number
that's too large for the column is an error ``22003``, and a string that's too
long is an error ``22001``.

The result (such as ``INSERT 2``) contains the number of rows inserted. A query
without any rows is ``INSERT 0`` with a warning ``02000`` (no data).

RETURNING
---------

With ``RETURNING``, the result is a row for each row that's inserted (including
the values of defaults and identity columns), like a query, rather than the
number of rows. The list is the same as the list of a ``SELECT``, and a column
can be qualified with the name of the table:

.. code-block:: sql

  CREATE TABLE products (id INT GENERATED ALWAYS AS IDENTITY, title VARCHAR(50));
  INSERT INTO products (title) VALUES ('Kettle'), ('Toaster') RETURNING id, products.title;
  -- msg: CREATE TABLE 1
  -- ID: 1 TITLE: Kettle
  -- ID: 2 TITLE: Toaster

It's the same as ``SELECT ... FROM NEW TABLE (INSERT ...)`` (see
:doc:`select`). ``UPDATE`` and ``DELETE`` can also have a ``RETURNING`` (see
:doc:`update` and :doc:`delete`). ``RETURNING`` isn't standard SQL, so it's
flagged as ``V119-01`` (see :doc:`sql-flagging`).

Examples
--------

.. code-block:: sql

  CREATE TABLE products (title VARCHAR(50), price NUMERIC(10, 2));
  INSERT INTO products (title, price) VALUES ('Instant Pot', 144.89);
  INSERT INTO products (title, price) VALUES ('Kettle', 30), ('Toaster', 25.5);
  INSERT INTO products VALUES ('Blender', 60);
  INSERT INTO products (title, price)
    SELECT title, price * 2 FROM products WHERE price < 30;
  SELECT * FROM products;
  -- msg: CREATE TABLE 1
  -- msg: INSERT 1
  -- msg: INSERT 2
  -- msg: INSERT 1
  -- msg: INSERT 1
  -- TITLE: Instant Pot PRICE: 144.89
  -- TITLE: Kettle PRICE: 30.00
  -- TITLE: Toaster PRICE: 25.50
  -- TITLE: Blender PRICE: 60.00
  -- TITLE: Toaster PRICE: 51.00
