Keywords
========

A reserved word can't be used as the name of an entity (such as a table or a
column), unless it's quoted. The reserved words are those of SQL:2023 (ISO/IEC
9075-2:2023, 5.2). For example, ``ORDER`` is a reserved word:

.. code-block:: sql

   CREATE TABLE order (x INT);
   -- error 42601: syntax error: unexpected ORDER at line 1, column 14 near "CREATE TABLE order ("; hint: ORDER is a reserved word, so it must be quoted to be used as a name, such as "ORDER" (see https://vsql.readthedocs.io/en/latest/keywords.html)

   CREATE TABLE "ORDER" (x INT);
   -- msg: CREATE TABLE 1

A quoted name keeps its case, so ``"ORDER"`` is the same name as an unquoted
``order`` would be, but ``"order"`` is a different one.

A non-reserved word, such as ``NAME``, has a meaning in some statements, but can
still be used as a name without quotes. The extension key words are those of
vsql's extensions (see :doc:`sql-flagging`), such as ``INDEX`` and ``LIMIT``, and
can also be used as a name without quotes.

A name can have up to 128 characters, quoted or not. Longer names are a
``42601`` error.

See :doc:`identifiers` for the rules of regular and quoted names.
